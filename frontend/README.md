# Frontend — Estoque Delta

UI Next.js do Estoque Delta. A documentação completa do projeto (backend, banco, API, fluxos) está na [raiz do repositório](../README.md).

```powershell
npm install
# crie .env.local a partir de .env.example
npm run dev
```

App em http://127.0.0.1:3000. A API precisa estar em http://127.0.0.1:8000.
